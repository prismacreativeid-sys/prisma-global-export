Dashboard resmi pengelolaan konten website ini menggunakan Pages CMS, yang terhubung ke repositori GitHub milik Anda.

Masuk ke dashboard

Setelah repositori GitHub dikonfigurasi, login ke Pages CMS untuk mengunggah foto, mengganti logo, dan menambah produk.

Buka Dashboard Pages CMS ↗
Keamanan: Tidak ada kata sandi admin tersimpan di website publik ini. Hanya akun GitHub yang diberi akses ke repositori yang dapat menyimpan perubahan.

Aktivasi pertama kali

  1. Buat akun GitHub dan unggah semua isi folder ZIP ini ke satu repositori.
  2. Buka app.pagescms.org, login GitHub, lalu izinkan Pages CMS mengakses repositori yang benar.
  3. Pilih menu 01 · Branding and Company untuk logo, kontak, dan profil.
  4. Pilih menu 02 · Export Products untuk mengubah foto, deskripsi, status, serta menambah dan menghapus produk.
  5. Hubungkan repositori yang sama ke Netlify agar setiap perubahan tersimpan dan terbit otomatis.

RFQ buyer tidak masuk ke Pages CMS. Buka dashboard Netlify → Forms untuk melihat permintaan harga dan mengatur notifikasi email.
